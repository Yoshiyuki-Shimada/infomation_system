# システムアップデート機能

## 方式

実行PCは `bin/update_agent.ps1` を常駐させ、更新要求フォルダを監視します。
メインPCは `bin/create_update_package.ps1` で更新zipと要求ファイルを作成し、実行PCが監視しているフォルダへ送信します。

## 実行PCの監視フォルダ

既定値は次のフォルダです。

```powershell
C:\infomation_system_updates\inbox
```

変更する場合は、実行PCの `bin/update_config.json` を作成します。

```json
{
  "watchPath": "C:\\infomation_system_updates\\inbox",
  "pollSeconds": 5,
  "restartAfterUpdate": true,
  "authToken": "メインPCと実行PCで同じ長い合言葉"
}
```

`start.bat` 実行時に `update_agent.ps1` も自動起動します。
`authToken` が未設定の場合、更新要求を見つけても適用しません。

## 実行PCの共有設定

実行PCで `bin\setup_update_share.bat` を管理者として実行します。
共有用の `infoupdate` ユーザーを作り、次の共有を書き込み可能にします。

```text
\\実行PC名\infomation_update_inbox
```

## メインPCから更新を送る

共有フォルダに送る例です。

```powershell
.\bin\create_update_package.ps1 -Destination "\\実行PC名\infomation_system_updates\inbox" -AuthToken "メインPCと実行PCで同じ長い合言葉"
```

USBに送る場合は、USB内の任意フォルダを指定します。

```powershell
.\bin\create_update_package.ps1 -Destination "E:\infomation_system_updates\inbox" -AuthToken "メインPCと実行PCで同じ長い合言葉"
```

メインPC側にも `bin\update_config.json` を作成して `authToken` を入れておけば、コマンドの `-AuthToken` は省略できます。

## 実行PCでの処理

1. 更新要求を検知
2. 画面をアップデート中表示へ切り替え
3. HTML、PowerShell、Edgeなどの実行中プロセスを停止
4. 現在のシステムを `_update\backup` にバックアップ
5. 更新zipを展開してシステムへコピー
6. `package\monitor_css` を `monitor_css` として直下へ反映
7. `temp` を削除して再作成
8. 完了後に再起動

## 注意

`monitor_css` はメインPC側では `package\monitor_css` のままにします。
実行PCではアップデート適用時に `monitor_css` が直下へコピーされます。
